## Scope

This FIX closes the semantic ownership mismatch for `thesis_formalize`,
`catalyst_map`, and `thesis_refresh`. It does not redesign the W4
deterministic contracts, add a second Skill layer, add an Agent/Planner/runtime
layer, or change Knowledge Schema or canonical persistence boundaries.

## Semantic ownership closure

- `thesis_formalize` accepts a narrative, bounded attributable evidence, and
  optional structured hints. `ReasoningExecutor` proposes propositions,
  evidence basis, horizons, dependencies, verification conditions, and gaps.
  `formalizeThesis()` remains the deterministic graph, source, cycle, and
  load-bearing validator.
- `catalyst_map` accepts a formalized thesis, optional expectation gaps, and
  attributable event evidence without caller-supplied proposition links.
  `ReasoningExecutor` proposes event mappings. `mapCatalysts()` remains the
  deterministic date, timing, status, proposition, and gap validator.
- `thesis_refresh` accepts a prior snapshot and new dated evidence without
  caller-supplied target or relation labels. `ReasoningExecutor` classifies
  targets and relations. `refreshThesis()` remains the deterministic PIT,
  targeted-delta, no-drift, and kill-criterion owner.

Each semantic entrypoint sends structured output through a bounded validator,
allows exactly one bounded repair, and fails closed on a second invalid result.
Generated refs are restricted to supplied proposition, gap, event, and source
allowlists. Source dates and event dates are preserved from input evidence;
future refresh evidence is rejected by the existing deterministic path.
